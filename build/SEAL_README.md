# Seal + Signature image

Place your combined **seal + signature** image in this folder as:

    public/seal.png

Requirements:
- PNG (or JPG renamed to .png), ideally with a transparent background.
- Landscape-ish proportions work best (e.g. ~800×400). The generator preserves
  the aspect ratio automatically.

Once placed, it is embedded into every generated document (offer letter,
completion certificate, performance award). Until then, the admin console shows
a warning and lets you upload one temporarily for testing.
